# RFC-0001: Voluntary Order Without Rulers

## Defining a Stateless Society

This repository contains RFC-0001, a formal structural specification for evaluating whether a social system qualifies as stateless.

RFC-0001 is published by **StatelessCo** and authored by Rick Simnett. Copyright is held by The Stateless Holdings Company and the work is released under CC BY 4.0 (see LICENSE.md).

The RFC derives a single invariant:

> **Voluntary Order Without Rulers**

Rather than treating anarchism as an economic system, political ideology, cultural identity, or institutional preference, RFC-0001 approaches statelessness as a structural classification problem.

Its purpose is not to prescribe how society should be organized.

Its purpose is to identify the minimal structural conditions required for a system to qualify as stateless.

---

## Purpose

This RFC attempts to answer a single question:

**What must be true for a society to be considered stateless?**

The document derives a structural invariant and evaluates the conditions necessary to preserve that invariant under repeated interaction, disagreement, scale, and institutional complexity.

The resulting framework provides a method for distinguishing between systems that remain stateless and systems that reintroduce rulership through structural authority.

---

## Scope

RFC-0001 defines qualification criteria.

It does **not**:

* Define property norms
* Prescribe economic systems
* Define justice systems
* Define governance protocols
* Mandate institutional structures
* Resolve transition strategies
* Define specific implementation architectures

These are implementation-level concerns.

RFC-0001 defines only the structural constraints that such implementations must satisfy in order to qualify as stateless.

---

## Core Invariant

The invariant derived by this RFC is:

> **Voluntary Order Without Rulers**

A ruler is defined structurally as any agent or rule-system possessing the authority to impose binding outcomes on others without their agreement.

If such authority exists, the system fails qualification.

If autonomous coordination persists without rulers, the system satisfies the invariant.

## Derived Constraints

RFC-0001 derives and evaluates six structural constraints:

### Constraint 1 — Agency & Identity

Voluntary order requires accountable agents possessing:

* Intentionality
* Continuity
* Attributability

### Constraint 2 — No Initiated Coercion

Initiated force, fraud, or scope expansion creates rulership and fails the invariant.

### Constraint 3 — Privacy

Privacy defines consent-governed informational boundaries between agents.

### Constraint 4 — Transparency

Transparency preserves informed consent within systems of voluntary coordination.

### Constraint 5 — Exit

Participation must remain revocable while preserving scope-bound obligations.

### Constraint 6 — Interoperability

Distinct voluntary systems must be capable of cooperation without asserting authority over one another.

---

## Qualification Checklist

A system qualifies as stateless if and only if all of the following remain true:

* No unilateral authority exists
* Participation is voluntary and revocable
* Obligations remain scope-bound
* No initiated coercion is permitted
* Identity continuity enables accountability
* Interoperability remains consent-scoped

Violation of any condition constitutes structural failure.
